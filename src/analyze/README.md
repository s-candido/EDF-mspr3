# Data Analysis Notebook

This directory contains exploratory data analysis (EDA) and feature selection for the EDF Energy Consumption Prediction project.

## Files

- **`notebook.ipynb`** - Main Jupyter notebook for data exploration and feature selection
- **`selected_features.json`** - Exported list of selected features (generated after running notebook)
- **`analysis_report.txt`** - Text report with analysis findings (generated after running notebook)
- **`*.png`** - Visualization files generated by the notebook

## Notebook Overview

The notebook performs the following analysis:

### 1. Setup & Data Loading
- Imports necessary libraries (pandas, numpy, matplotlib, seaborn, sklearn)
- Loads energy consumption data from `../data/` directory
- Displays basic dataset information

### 2. Data Exploration & Understanding
- Summary statistics for all variables
- Missing value analysis
- Target variable distribution (histograms, box plots, Q-Q plots)
- Temporal patterns (hourly, daily, monthly, yearly consumption)
- Production mix analysis

### 3. Feature Engineering & Cleaning
- Creates datetime features (hour, day, month, dayofweek, weekend)
- Generates lag features (t-1, t-24, t-168)
- Computes rolling window features (24h, 168h)
- Calculates difference features (t-1)
- Handles missing values and ND ("Not Data") entries

### 4. Correlation Analysis
- Full correlation matrix heatmap
- Correlation with target variable (consommation)
- Feature importance using Random Forest
- Multicollinearity analysis (Variance Inflation Factor)
- Scatter plots for top correlated features

### 5. Feature Selection
- Combines three methods:
  1. Top features by correlation
  2. Top features by Random Forest importance
  3. Low multicollinearity (VIF < 10)
- Exports selected features to `selected_features.json`

### 6. Summary & Recommendations
- Generates comprehensive analysis report
- Creates visualizations
- Provides recommendations for model development

## Key Findings

### Temporal Patterns
- **Peak hours**: 8-10 AM and 6-8 PM
- **Seasonal**: Higher consumption in winter (Dec-Feb), lower in summer (Jul-Aug)
- **Weekly**: Weekdays higher than weekends

### Highly Predictive Features
1. **Forecasts** (`prevision_j`, `prevision_j_1`) - Most predictive
2. **Nuclear production** (`nucleaire`) - Strong correlation with consumption
3. **Lag features** - Previous hour consumption is highly predictive
4. **Temporal features** - Hour, day of week, month capture patterns

### Production Mix
- **Nuclear**: Primary baseline load source
- **Wind/Solar**: Variable, weather-dependent
- **Hydropower**: Significant seasonal contributor

## Recommendations

1. **Use forecast features** as primary predictors (prevision_j, prevision_j_1)
2. **Include production mix**, especially nuclear power
3. **Add temporal features** (hour, dayofweek, month, weekend)
4. **Consider lag features** for time series modeling
5. **Integrate weather data** (temperature, humidity) for seasonal patterns
6. **Monitor data quality** for ND values and missing data
